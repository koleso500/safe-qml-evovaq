# HMDA input data

Place `hmda_2017_ny_all-records_labels.csv` in this directory before training.

Obtain the 2017 New York **All records** CSV with **Plain language labels and HMDA codes** from the [CFPB historical HMDA download page](https://www.consumerfinance.gov/data-research/hmda/historic-data/).

The reference input has 446,902 rows and 78 columns.

Raw CSVs are excluded from Git and the submission archive. See the main README for preprocessing and the fixed stratified 10% sample used by the paper.
